# C6 — empirical alpha tradeoff: BLOCKED

The paper illustrates low-alpha drift and high-alpha stability on a 10D GMM and
images. C6 is not promoted from partial alignment: the exact finite-KDE acceleration
is unpublished, the image protocol is incomplete, and CPU-only full recursive image
training is outside the measured feasible scope.

## Route 1 — paper-scale GMM population closure

HF run `aa8213ff-934e-4c9b-b898-669f3e7859a7`, Git
`6bdd221a95fa1782cc0816d79aaaf3e0a63f5ea6`: 10 dimensions, five components,
sigma=h=0.6, N=100,000, 20 generations, alpha 0.1/0.5/0.9, ten seeds, eight
workers, and nine million stochastic checkpoint samples.

| alpha | generation-20 relative total-second-moment drift |
| ---: | ---: |
| 0.1 | +108.38% |
| 0.5 | +24.72% |
| 0.9 | +13.77% |

The 95% dispersion intervals are strictly ordered low>mid>high; maximum
sample-to-population calibration z is 1.922. Setting h=0 removes alpha-dependent
accumulation. This is aligned, but the exact population endpoint substitutes for
the literal empirical 100,000-center KDE and 500-step solver.
[Raw route 1 JSON](/evidence/artifacts/C6/route1/raw_formal_summary.json).

## Route 2 — Fashion-MNIST protocol and CPU lower bound

Eleven material fields are missing: widths, multipliers, residual-block count,
attention, batch size, beta schedule, training diffusion horizon, normalization,
seeds, validation split, and stopping metric/delta. A complete mock protocol passes
the same schema. A deliberately tiny 737-parameter CNN measured 15,249.6 training
images/s and 56,676.6 inference image-steps/s; the stated 160M training examples and
750M sampler image-steps still give an optimistic 6.59-hour lower bound before
regressors, metrics, or I/O. This benchmark is not a reproduction.
[Raw route 2 JSON](/evidence/artifacts/C6/route2/raw_formal_summary.json).

## Route 3 — CIFAR-10 source contract

The audit preserves Figure 9's positive result: post-transient eta≈0.25–0.35.
It also finds 20 CIFAR-specific protocol fields and four direct alpha-tradeoff
evidence items absent. The subsection-wide d=784 matches Fashion-MNIST, not
CIFAR-10's 3072 pixels; this is recorded only as ambiguity. The complete-protocol
control passes. [Raw route 3 JSON](/evidence/artifacts/C6/route3/raw_formal_summary.json).

## Route 4 — mandatory falsification search

No candidate satisfies every assumption and contradicts the source outcome:

- the population-KDE result aligns and uses a substituted solver;
- h=0 contradicts the order but violates fixed h=0.6;
- +13.77% at alpha=0.9 cannot contradict “stable” without a source threshold;
- overlapping CIFAR eta curves measure observability, not distributional drift.

The independent checker does accept a synthetic claim with an explicit ≤10% drift
threshold, proving it can recognize a valid contradiction. That threshold is not
attributed to the paper. [Checker](/evidence/code/repro_campaign/check_claim6_falsification.py)
and [raw route 4 JSON](/evidence/artifacts/C6/route4/raw_formal_summary.json).

## Reproduction and compute

All four routes use:

```bash
uv run --frozen python -m repro_campaign.run
```

This is the **fixed command** for every experiment node.
HF `cpu-upgrade` advertised 8 vCPU; the container exposed 64 logical/affinity CPUs,
with active parallel work bounded to 8. Jobs took 58, 69, 69, and 69 seconds;
verifier runtimes 34.794, 44.518, 42.701, and 41.618 seconds.

**Unblockers:** author code or exact GMM acceleration and raw seeds; complete
Fashion/CIFAR configs and checkpoints; raw per-generation image metrics; and
sufficient CPU time after the protocol is identifiable.

**Limitation:** none of the partial, source-audit, feasibility, or failed
counterexample routes is presented as verification or falsification of full C6.
