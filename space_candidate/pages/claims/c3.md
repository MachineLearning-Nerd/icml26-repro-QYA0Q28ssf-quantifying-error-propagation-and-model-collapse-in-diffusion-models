# C3 — Theorem 3.4

Current pre-publication status: **exact certificate and two-sided calibration pending
a formal run**.

Under A1–A4, the theorem combines C2 with

`chi2 <= 4*eps_star^2 + c*eps_star^4`.

The asymptotic equivalence additionally requires a uniform `eta` floor strictly
above zero. The verifier checks that qualifier explicitly; the `eta=0` rows are
edge controls and never count as equivalence evidence. A mutation changing the
upper coefficient `4` to `3.9` must be rejected, and a numerical false upper bound
`chi2<=0.5*eps_star^2` must fail.
