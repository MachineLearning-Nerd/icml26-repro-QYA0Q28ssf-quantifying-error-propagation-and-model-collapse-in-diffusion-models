# C5 — Theorem 4.2

Current pre-publication status: **FALSIFIED certificate implemented; formal run
pending**.

The paper defines `f asymp g` by fixed positive finite multiplicative constants.
Theorem 4.2 assumes a summable score-energy sequence and states, with
`C_bias>0`,

`D_(N+1)+C_bias asymp discounted_energy_N + decayed_initial_N`.

For every `alpha>0`, summability makes the complete right side tend to zero. Since
chi-squared divergence is nonnegative, the left side is always at least the fixed
positive `C_bias`. No finite upper multiplicative constant can satisfy the displayed
equivalence.

The appendix proves only weaker additive inequalities, including
`D_N <= decayed_initial + discounted_energy + C_bias`; it does not prove the main
display. The verifier must stop calling this a falsification if `C_bias` is changed
to zero or added to the right side. This result challenges only Theorem 4.2 as
written, not those weaker additive stability bounds.
